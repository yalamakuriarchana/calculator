🧮 Calculator Web App

A responsive, browser-based calculator built with HTML, CSS, and
JavaScript. The project includes basic arithmetic operations, keyboard
support, calculation history, Local Storage, and a dark/light theme
toggle.

✨ Features

➕ Addition, subtraction, multiplication, and division

🔢 Decimal number input

🧹 Clear (AC) and delete (DEL) controls

⌨️ Keyboard support:

Number and operator keys to enter expressions

Enter to calculate

Backspace to delete the last character

Escape to clear the display

🧾 Calculation history with a clear-history option

💾 Saves calculation history in browser Local Storage

🌗 Dark and light themes, with the selected theme saved in Local
Storage

📱 Responsive layout for desktop, tablet, and mobile screens

🛠️ Built With

HTML5 --- page structure

CSS3 --- styling, layout, hover effects, and responsive design

JavaScript --- calculator operations and interactive features

Web Storage API (Local Storage) --- saves history and theme
preference

🚀 Run Locally

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open index.html in a browser, or run it using the Live Server
extension.

No installation or build process is required.

🌐 Live Demo

GitHub Pages: https://YOUR-USERNAME.github.io/Calculator/

Replace YOUR-USERNAME with your GitHub username. If GitHub Pages is
not enabled yet, open the repository's Settings → Pages, select the
main branch and /(root) folder, then save.

🧪 Try It

Enter a calculation such as 5 + 3.

Press = or Enter to see the result.

Check the calculation in the history section.

Refresh the page to verify that history and theme preference are
saved.

Switch between dark and light mode and try the calculator on a
narrow screen.

🎯 Project Objective

This project was created to practice front-end web development
fundamentals, including DOM interaction, event handling, CSS layout,
responsive design, and browser Local Storage.
